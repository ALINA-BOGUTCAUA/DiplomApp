Мобильное приложение для обнаружения голосового мошенничества

Описание приложения

Приложение представляет собой Android-приложение для обнаружения синтезированного и преобразованного голоса (voice spoofing). Основная цель приложения заключается в выявлении аудиозаписей, созданных с помощью технологий синтеза речи или голосовых преобразователей, которые могут использоваться мошенниками для обмана систем биометрической аутентификации.

Архитектура приложения

Приложение построено на основе трехуровневой архитектуры, которая включает уровень представления, уровень бизнес-логики и уровень данных.

Уровень представления (UI Layer) обеспечивает взаимодействие пользователя с приложением и состоит из нескольких экранов. Главный экран MainActivity предназначен для загрузки и записи аудио, а также запуска проверки на наличие синтезированного голоса. Экран настроек SettingsActivity позволяет пользователю настраивать параметры работы приложения. Экран истории HistoryActivity отображает историю всех выполненных проверок с датами и результатами. Экран оповещений FraudAlertActivity показывает предупреждения о обнаруженном мошенничестве.

Уровень бизнес-логики (Business Logic Layer) содержит основную логику обработки данных и анализа аудио. Класс AudioClassifier отвечает за работу с моделями машинного обучения, загружает модели и выполняет анализ аудио для определения синтезированного голоса. Сервис CallMonitoringService обеспечивает мониторинг телефонных звонков и может автоматически проверять голос собеседника на наличие признаков синтеза.

Уровень данных (Data Layer) отвечает за хранение и управление данными. Класс AppDatabase представляет собой SQLite базу данных для хранения истории проверок с использованием библиотеки Room. Класс CheckHistory является сущностью для хранения отдельной записи проверки в базе данных. Класс SettingsRepository обеспечивает доступ к настройкам приложения и их сохранение.

ML-модели

Приложение использует пять моделей машинного обучения для анализа аудио и определения синтезированного голоса.

Модель CNN (Convolutional Neural Network) представляет собой сверточную нейронную сеть, которая используется для классификации аудиоспектрограмм. Модель анализирует частотные характеристики аудио и выявляет паттерны, характерные для синтезированной речи.

Модель LSTM (Long Short-Term Memory) является рекуррентной нейронной сетью долгой краткосрочной памяти, которая предназначена для анализа временных рядов аудио. Модель учитывает последовательность звуковых данных и обнаруживает аномалии в структуре речи.

Модель RCNN (Recurrent Convolutional Neural Network) представляет собой комбинированную архитектуру, объединяющую преимущества сверточных и рекуррентных сетей. Модель анализирует как частотные, так и временные характеристики аудио.

Модель RF (Random Forest) является ансамблевым методом машинного обучения на основе случайного леса. Модель использует множество решений деревьев для повышения точности классификации.

Модель Wav2Vec представляет собой модель для извлечения признаков из аудио на основе архитектуры wav2vec. Модель преобразует сырые аудиоданные в информативные признаки для последующего анализа.

Функциональность приложения

Приложение предоставляет пользователю следующие основные функции.

Функция загрузки аудиофайла позволяет выбрать аудиофайл из памяти устройства или загрузить его по URL-ссылке. Пользователь может выбрать файл в любом поддерживаемом формате аудио.

Функция записи голоса обеспечивает запись голоса пользователя с микрофона устройства в реальном времени. Запись сохраняется в формате MP4 и доступна для последующего анализа.

Функция воспроизведения позволяет прослушать выбранный или записанный аудиофайл перед отправкой на анализ.

Функция анализа голоса выполняет проверку аудио на признаки синтеза или преобразования с использованием выбранных моделей машинного обучения. Результат проверки отображается на экране.

Функция выбора модели позволяет пользователю выбрать конкретную модель для анализа или использовать все модели одновременно.

Режимы проверки

Приложение поддерживает три режима проверки аудио.

Быстрая проверка использует только модель CNN и выполняется через сервер. Этот режим обеспечивает минимальное время анализа при достаточной точности.

Полная проверка использует все пять моделей машинного обучения и выполняется через сервер. Этот режим обеспечивает наиболее точный результат за счет ансамбл��вого анализа.

Выбор модели позволяет пользователю самостоятельно выбрать конкретную модель для анализа.

Дополнительные функции

Помимо основных функций, приложение предоставляет дополнительные возможности.

История проверок сохраняет все выполненные проверки в базе данных и позволяет просмотреть их в любое время. Каждая запись содержит имя файла, результат, использованную модель, уверенность и дату проверки.

Настройки позволяют пользователю настроить параметры работы приложения, включая пороговые значения и предпочтительные модели.

Мониторинг звонков представляет собой фоновый сервис, который автоматически проверяет голос собеседника во время телефонного звонка.

Поток данных

Процесс анализа аудио включает следующие этапы. Сначала пользователь выбирает аудиофайл из памяти устройства или записывает голос с микрофона. Затем аудио декодируется в PCM данные с параметрами 16 бит и 16 кГц. Класс AudioClassifier загружает выбранные модели машинного обучения. Модели выполняют классификацию, извлекая признаки из аудио и предсказывая вероятность мошенничества. Результаты анализа агрегируются и отображаются пользователю на экране. Информация о проверке сохраняется в историю для последующего просмотра.

Технические детали

Приложение имеет следующие технические характеристики. Минимальная длительность аудио для анализа составляет 1 секунду. Частота дискретизации аудио составляет 16 кГц. Формат входных данных представляет собой массив FloatArray с 16000 элементами. Порог принятия решения о синтезированном голосе составляет 0,5 (50%).

База данных

История проверок хранится в SQLite базе данных с использованием библиотеки Room. Каждая запись содержит имя файла, путь к файлу, использованную модель, тип проверки, результат проверки (Да/Нет), уверенность в процентах, флаг мошенничества и дату/время выполнения проверки.
