Результаты работы приложения

Выходные данные

После выполнения анализа аудиозаписи приложение предоставляет следующие результаты.

Основной результат проверки представляет собой бинарный ответ на вопрос о наличии синтезированного голоса. Значение "Да" означает, что голос признан синтезированным или преобразованным с использованием технологий синтеза речи (SPOOF). Значение "Нет" означает, что голос признан реальным и не содержит признаков синтеза (REAL).

Уверенность модели представляет собой числовое значение от 0,0 до 1,0, которое отображается в процентном формате (от 0% до 100%). Это значение показывает степень уверенности модели в полученном результате. Чем выше значение уверенности, тем более достоверным считается результат.

Использованная модель указывает название модели или список моделей, которые использовались для анализа. Формат отображения может быть "CNN" для быстрой проверки или "CNN + LSTM + RCNN + RF + Wav2Vec" для полной проверки.

Результаты всех моделей отображаются при выполнении полной проверки. Для каждой модели показывается полученная вероятность и классификация. Например, CNN: 0.872 - SPOOF означает, что модель CNN определила вероятность синтезированного голоса 87,2%. LSTM: 0.654 - SPOOF означает вероятность 65,4%. RCNN: 0.123 - REAL означает вероятность 12,3% синтеза. RF: 0.891 - SPOOF означает вероятность 89,1%. Wav2Vec: 0.234 - REAL означает вероятность 23,4%.

Примеры результатов

Рассмотрим несколько примеров результатов работы приложения.

Первый пример демонстрирует случай обнаружения мошенничества. Результат проверки: Да. Уверенность: 87%. Использованная модель: CNN. Результаты всех моделей: CNN - 87,2%, LSTM - 93,4%, RCNN - 81,2%, RF - 95,6%, Wav2Vec - 44,5%. Большинство моделей (4 из 5) определили голос как синтезированный, что указывает на высокую вероятность мошенничества.

Второй пример демонстрирует случай реального голоса. Результат проверки: Нет. Уверенность: 92%. Использованная модель: CNN. Результаты всех моделей: CNN - 3,4%, LSTM - 8,7%, RCNN - 15,6%, RF - 2,3%, Wav2Vec - 1,2%. Все модели определили голос как реальный с высокой степенью уверенности.

Третий пример демонстрирует неопределенный результат. Результат проверки: Нет. Уверенность: 54%. Использованная модель: CNN. Результаты всех моделей: CNN - 54,3%, LSTM - 62,1%, RCNN - 48,9%, RF - 56,7%, Wav2Vec - 51,2%. Модели показывают противоречивые результаты, что указывает на неопределенность и рекомендует повторную проверку.

Интерпретация результатов

Порог принятия решения определяет границу между синтезированным и реальным голосом. Если полученная вероятность превышает 0,5 (50%), голос считается синтезированным. Если вероятность не превышает 0,5 (50%), голос считается реальным.

Степень уверенности классифицируется по процентному значению. Значение уверенности в диапазоне 90-100% указывает на высокую достоверность результата. Значение в диапазоне 70-89% указывает на среднюю достоверность. Значение в диапазоне 50-69% указывает на низкую достоверность. Значение ниже 50% считается неопределенным результатом.

Согласованность моделей важна при использовании всех пяти моделей. Если большинство моделей показывают SPOOF, это указывает на высокую вероятность мошенничества. Если большинство моделей показывают REAL, голос считается реальным. Если голоса делятся пополам (50/50), результат считается неопределенным, и рекомендуется повторная проверка с использованием другого аудио.

Сохранение в историю

Каждый результат проверки автоматически сохраняется в историю проверок. Запись содержит следующие данные: имя файла (название аудиофайла), путь (URI аудиофайла), модель (использованная модель), тип проверки (fast/full/model), результат (Да/Нет), уверенность (процент от 0 до 100), флаг мошенничества (true/false), дата (аватически установленная дата и время выполнения проверки).

Обработка ошибок

При возникновении ошибок в процессе анализа приложение отображает соответствующие сообщения. Сообщение "Ошибка: <сообщение>" отображается при проблемах с анализом аудио. Сообщение "Аудио дорожка не найдена" отображается при неверном формате файла. Сообщение "Сначала выберите аудиофайл" отображается при отсутствии файла для анализа.
